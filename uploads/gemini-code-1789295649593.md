# DC_PLATFORM_UPDATE_INSTRUCTIONS.md

## 1. Overview
This guide provides precise, platform-compliant refactoring instructions for the **Poseidon Network** single-page marketing website. Per Design Component (DC) platform constraints, **all component styling must remain strictly inline**. 

External stylesheets, CSS custom properties (`var()`), and global class definitions are prohibited. The `<helmet><style>` tag is strictly reserved for `@font-face`, `@keyframes`, and essential resets.

---

## 2. Color Repetition & Palette Management

Because CSS variables are disallowed inside `style=""` attributes, manage theme values at the template/JS module level using a single source of truth prior to rendering.

### Centralized JS Theme Constants
Define color palettes as immutable JavaScript objects:

```javascript
const PALETTE = {
  light: {
    bgPrimary: '#ffffff',
    bgSecondary: '#f8fafc',
    textMain: '#0f172a',
    textMuted: '#64748b',
    brand: '#0284c7',
    brandHover: '#0369a1',
    border: '#e2e8f0',
  },
  dark: {
    bgPrimary: '#0f172a',
    bgSecondary: '#1e293b',
    textMain: '#f8fafc',
    textMuted: '#94a3b8',
    brand: '#38bdf8',
    brandHover: '#0ea5e9',
    border: '#334155',
  }
};
