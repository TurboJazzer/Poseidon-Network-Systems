# MARKETING_SITE_UPDATE_INSTRUCTIONS.md

## 1. Overview
This guide provides precise, standalone instructions for updating the **Poseidon Network** single-page marketing website. Because this project uses inline-styled HTML design components without a build pipeline (no Node.js, Tailwind, or bundling tools), all refactoring must remain lightweight, dependency-free, and directly editable in vanilla HTML/CSS/JS.

---

## 2. Core Architecture Setup

### CSS Custom Properties (`<style>` Header Block)
Consolidate repetitive inline hex values into standard CSS custom properties defined at the top of your single HTML file inside a `<style>` block.

```html
<style>
  :root {
    /* Color Palette */
    --color-bg-primary: #ffffff;
    --color-bg-secondary: #f8fafc;
    --color-text-main: #0f172a;
    --color-text-muted: #64748b;
    --color-brand: #0284c7;
    --color-brand-hover: #0369a1;

    /* Spacing & Layout */
    --max-width-container: 1200px;
    --radius-button: 8px;
    --transition-fast: 200ms ease;
  }

  /* Dark Theme Override */
  [data-theme="dark"] {
    --color-bg-primary: #0f172a;
    --color-bg-secondary: #1e293b;
    --color-text-main: #f8fafc;
    --color-text-muted: #94a3b8;
    --color-brand: #38bdf8;
    --color-brand-hover: #0ea5e9;
  }

  body {
    background-color: var(--color-bg-primary);
    color: var(--color-text-main);
    font-family: system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
    margin: 0;
    padding: 0;
  }
</style>
